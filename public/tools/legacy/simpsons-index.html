Simpson's Diversity Index

D = N(N − 1) ÷ Σn(n − 1)

Where:

  • D = Diversity index (higher = more diverse)
  • N = Total number of organisms of all species
  • n = Number of organisms of one particular species
  • Σ = "Sum of" you calculate n(n−1) for each species and add them all together.
