Lincoln Index (Mark-Recapture)

N = (n1 × n2) ÷ m2

Where:

  • N = Estimated total population size
  • n1 = Number of animals captured, marked, and released in the 1st sample
  • n2 = Total number of animals captured in the 2nd sample
  • m2 = Number of marked animals found in the 2nd sample (recaptures)
