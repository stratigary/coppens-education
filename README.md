# coppens.education

Mr. Coppens's class website for AP Environmental Science, IB Biology Year 1, Environmental Science and (some years) Freshman Honors Biology.

* **Today**: a card for each course showing today's (or the next) lesson, the reading due, in-class work and the next class.
* **Course pages**: the year's unit trail, a unit calendar with tests, quizzes and short-block days flagged, earlier units collapsed, and a side panel of resources for each unit.
* **Tools & simulations**: a built-in carrying-capacity explorer plus the 14 calculators carried over from the old Google Site.
* **Digital textbooks** (Google Drive, school accounts only) and **Contact** (email).

Calendars are read live from the "Website" tab of each unit-plan Google Sheet, with a saved copy as a fallback. Assignments stay in Google Classroom.

Built with [Astro](https://astro.build), hosted on GitHub Pages, edited with [Pages CMS](https://pagescms.org).
